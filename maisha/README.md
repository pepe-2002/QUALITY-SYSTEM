# Maisha 🌺 — simulateur de vie

Jeu de simulation de vie inspiré de BitLife, entièrement en français, avec une
touche comorienne (prénoms, villes, événements locaux).

## Principe

Tu nais quelque part entre Moroni et Paris. Chaque pression sur **+ Âge** fait
passer un an : école, bac, université, emplois, relations, mariage, enfants,
achats (scooter, vedette, villa vue mer…), événements aléatoires, prison si tu
tentes le vol à l'étalage… jusqu'à la mort, avec un écran bilan et la
possibilité de recommencer une nouvelle vie.

- **Stats** : Santé, Bonheur, Intelligence, Apparence (0–100).
- **Onglets** : Emploi · Actifs · Relations · Activités (façon BitLife).
- **Sauvegarde automatique** dans le navigateur (localStorage) : on peut fermer
  la page et reprendre sa vie plus tard.

## Technique

- Un seul fichier : `index.html` (HTML + CSS + JS, zéro dépendance, hors-ligne).
- Compatible mobile (interface pensée téléphone d'abord).
- Thème clair et sombre automatiques.

## Déployer

Le fichier peut être ouvert directement dans un navigateur, ou déposé tel quel
sur n'importe quel hébergeur statique (Netlify, GitHub Pages…).
